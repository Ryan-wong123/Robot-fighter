# prompts.md — Starting each task

Use this to kick off any task. Tell an agent: **"Do M0-06"** (any id from [`task.md`](task.md)) and point it at this file. Everything the agent needs is below. The agent must follow [`AGENTS.md`](../AGENTS.md), finish prerequisites first, verify its own work, and let `tick_tasks.py` tick the box.

## Standard prompt (use for any task)

```
Do task <ID> from docs/task.md.
1. Read AGENTS.md, then the "Read first" docs listed for <ID> in docs/prompts.md.
2. Check its prerequisites ("after:" in docs/task.md) are all [x]. If not, stop and tell me.
3. Implement only what the task describes, following docs/coding_guidelines.md. No unrelated changes.
4. Add or update the checks for <ID> in Tools/tasks/verify.json (write real tests for logic).
   Update every doc your change affects in the same commit (AGENTS.md section 3.2) and run python3 Tools/tasks/check_docs.py.
5. Run: python3 Tools/tasks/tick_tasks.py --complete <ID>. Fix the code until it passes (exit 0).
   Never weaken a check. If the check cannot run here, say so and give me the manual verification steps.
6. Commit the code and docs/task.md together. Summarize what changed, what was verified, and what I must do in Unity/device.
```

## How "done" is decided

- Tasks with a check in `Tools/tasks/verify.json` are ticked `[x]` only when every command passes.
- Unity-dependent checks need `UNITY_PATH` (Unity editor binary) on the machine running the agent; otherwise the task becomes `[~]` and the owner confirms.
- Tasks marked "Owner task" cannot be completed by the agent alone. The agent prepares code/steps and the owner confirms.
